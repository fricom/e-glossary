# 에너지 산업 이해

에너지 업계 용어집. https://fricom.github.io/e-glossary/

## 업데이트

1. `index.html` 수정
2. `./deploy.sh "변경 내용"` 실행 → 커밋·푸시
3. 1~2분 뒤 사이트에 반영

공개 저장소이므로 사내 정보(협력사 관계, 내부 문서명, 직원 이름)는 넣지 않는다.

## 순서 원칙

섹션 번호는 쓰지 않는다. 섹션, 그룹, 그룹 안 용어 모두 쉬운 개념에서 어려운 개념으로, 작은 범위에서 큰 범위로 놓는다. 새 용어는 이 원칙에 맞는 자리에 끼워 넣는다.

## 색과 글자 크기 규칙

- 파랑 (`--accent`, 라이트 #2457d6 / 다크 #7ea2ff): 섹션 제목, 사이드바의 현재 섹션, 마우스를 올린 링크, 포커스 표시.
- 맑은 파랑 (`--group`, 라이트 #0a6bdb / 다크 #93c5fd): 섹션 안의 그룹 구분. 표의 그룹 행, 사이드바의 그룹 이름, 상세 창 상단의 그룹 라벨, 상세 창 안 표의 그룹 행.
- 맑은 파랑은 섹션 제목 파랑보다 밝고 맑게, 흰 배경과 사이드바 배경에서 글자 대비 4.5:1을 넘기는 값으로 정했다. 더 밝게 바꾸면 읽기 어려워진다.
- 글자 크기는 28 / 24 / 20 / 16 / 14 다섯 단계만 쓴다. 페이지 제목 28, 섹션 제목 20, 상세 창 제목과 본문 16, 보조 글자와 그룹 이름 14.
