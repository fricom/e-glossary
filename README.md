# 에너지 산업 이해

에너지 업계 용어집. https://fricom.github.io/e-glossary/

## 업데이트

1. `index.html` 수정
2. `./deploy.sh "변경 내용"` 실행 → 커밋·푸시
3. 1~2분 뒤 사이트에 반영

공개 저장소이므로 사내 정보(협력사 관계, 내부 문서명, 직원 이름)는 넣지 않는다.

## 용어 추가 방법

`index.html` 한 파일에 모든 내용이 있다. 용어 하나를 추가할 때 세 곳을 함께 고친다.

1. 표 행: 해당 섹션 표의 맞는 그룹 안에 `<tr data-id="t-이름">` 행을 넣는다. 칸은 용어 / 정식 명칭(없으면 빈 칸) / 한 줄 설명 / › 네 개.
2. 사이드바: 같은 섹션 목록(`nav-s번호`)의 같은 위치에 링크를 넣고, 섹션 옆 개수를 1 올린다.
3. 상세 데이터: `const DATA` 안에 `term, abbr, full, summary, html, group`을 넣는다. summary는 표의 한 줄 설명과 같게 둔다.

## 글쓰기 규칙

- 중학생~고등학생이 이해할 수준, '~입니다/~합니다' 체. 느낌표와 '~요' 말투는 쓰지 않는다.
- 한 줄 설명은 한 문장, 마침표로 끝낸다. 약어는 한국어 이름으로 시작한다.
- 용어 상세는 '쉽게 말하면 / 조금 더 자세히 / 예를 들면 / 함께 알면 좋은 용어' 순서. 주제·사례 글은 끝에 '정리'를 둔다.
- 큰따옴표 대신 작은따옴표, 대시는 키보드 하이픈만, 이모지 금지. 약어는 처음 나올 때 굵게.
- kW(순간의 힘)와 kWh(쌓인 총량)를 섞어 쓰지 않는다.

## 순서 원칙

섹션 번호는 쓰지 않는다. 섹션, 그룹, 그룹 안 용어 모두 쉬운 개념에서 어려운 개념으로, 작은 범위에서 큰 범위로 놓는다. 새 용어는 이 원칙에 맞는 자리에 끼워 넣는다.

## 색과 글자 크기 규칙

- 파랑 (`--accent`, 라이트 #2457d6 / 다크 #7ea2ff): 섹션 제목, 사이드바의 현재 섹션, 마우스를 올린 링크, 포커스 표시.
- 연한 회색 (`--group` 글자 라이트 #4a505c / 다크 #b4bac6, `--group-bg` 띠 라이트 #f1f3f6 / 다크 #22262d): 섹션 안의 그룹 구분. 표의 그룹 행은 회색 띠로, 사이드바의 그룹 이름과 상세 창 상단의 그룹 라벨은 회색 글자로. 큰 섹션(파랑 제목)과 작은 그룹(회색 띠)을 색으로 나눈다.
- 글자 크기는 28 / 24 / 20 / 16 / 14 다섯 단계만 쓴다. 섹션 제목 20, 상세 창 제목과 본문 16 (본문 상단 페이지 제목은 화면에서 숨김), 보조 글자와 그룹 이름 14.
